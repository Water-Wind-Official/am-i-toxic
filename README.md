# Am I Toxic?

A self-reflection quiz to help identify potential toxic behavioral patterns.

## About

This interactive quiz asks 15 questions about various scenarios and behaviors to help users identify any toxic biases or traits they might have. The quiz covers:

- Communication patterns
- Emotional intelligence
- Accountability and responsibility
- Boundary respect
- Manipulation tactics
- Empathy and support
- Mood management

## Features

- 15 comprehensive questions with multiple-choice answers
- Progress tracking with visual progress bar
- Score calculation (0-75 points)
- Personalized results with constructive feedback
- Four result categories ranging from "Excellent Self-Awareness" to "Significant Toxic Patterns"
- Actionable advice based on your score
- Ability to retake the quiz
- Responsive design for mobile and desktop

## How to Use

### Option 1: Open Locally
Simply open `index.html` in your web browser.

### Option 2: Run a Local Server
```bash
# Using Python 3
python3 -m http.server 8080

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8080
```

Then navigate to `http://localhost:8080` in your browser.

### Option 3: Deploy to GitHub Pages
1. Push this repository to GitHub
2. Go to Settings > Pages
3. Select your branch and save
4. Your site will be live at `https://yourusername.github.io/am-i-toxic`
